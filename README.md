# Flexbox Sandbox

Outil d'apprentissage interactif pour maîtriser CSS Flexbox — 20 exercices progressifs dans un seul fichier HTML.

## Démo

Ouvre `flexbox-sandbox.html` directement dans ton navigateur. Aucune installation requise.

## Exercices

20 exercices répartis en 4 niveaux :

**Niveau 1 — Bases**
1. Centrer un bloc
2. 3 éléments en ligne, à gauche
3. Espace égal entre 3 éléments
4. 3 éléments en colonne
5. Centrage parfait

**Niveau 2 — Mise en page**
6. Barre de navigation
7. Header avec bouton à droite
8. 3 cartes de hauteurs différentes
9. Texte en haut, bouton en bas
10. Footer avec 3 blocs

**Niveau 3 — Avancé**
11. 4 cartes sur toute la largeur
12. Un élément prend tout l'espace
13. Carte image + texte
14. Sidebar + contenu
15. Ligne de boutons alignés

**Niveau 4 — Expert**
16. Galerie avec retour à la ligne
17. Grille de 6 cartes responsive
18. Menu de tags multi-lignes
19. Section témoignages responsive
20. Page complète responsive

## Fonctionnalités

- Éditeur HTML + CSS avec aperçu en temps réel
- Indice, Solution et Explication pour chaque exercice
- Vérification automatique de la réponse
- Suivi de progression (barre + compteur)
- Fiche de synthèse complète débloquée à 100%
- Impression de la fiche (bouton Imprimer)
- Raccourcis clavier : `Tab` pour indenter, `Ctrl+Enter` pour exécuter

## Utilisation

```
Ouvrir flexbox-sandbox.html dans Chrome, Firefox ou Edge
```

Aucune dépendance, aucun serveur, aucune installation.
